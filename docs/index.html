BilaBot (Trợ lý giọng nói XiaoZhi AI) is a browser-based multi-assistant AI platform built on the Xiaozhi protocol.

Each assistant maintains its own independent identity, pairing, conversation history, connection, avatar, volume, and settings while sharing one unified interface.

Internally, BilaBot emulates multiple virtual ESP32 devices, but this implementation detail is abstracted away to provide a seamless multi-assistant experience.

Features

Multi-assistant architecture
Independent assistant sessions
Independent conversations
Independent Xiaozhi pairing
Independent connections
Per-assistant avatars
Per-assistant volume controls

Assistant Architecture

Each assistant maintains its own independent:

  • Device ID
  • Client ID
  • Pairing Token
  • WebSocket Session
  • Conversation History
  • Avatar
  • Audio Volume
  • Settings

Internally, every assistant behaves as its own virtual ESP32 device, while presenting one unified application to the user.
